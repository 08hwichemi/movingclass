3신청 방법 휴대폰으로 5분이면 끝나요

  1. 1
    부광고ON 접속 QR코드를 찍거나 주소창에 08hwichemi.github.io/movingclass 입력 → 학생
  2. 2
    처음 로그인 학번(예: 30101)과 이름 입력, 비밀번호 111111 → 학생 접속하기
  3. 3
    내 비밀번호 설정 숫자 6자리 새 비밀번호를 두 번 입력 → 변경하고 계속하기 (111111은 사용 불가)
  4. 4
    새 비밀번호로 다시 로그인 학번·이름과 방금 만든 비밀번호로 다시 학생 접속하기
  5. 5
    희망하는 수업 신청 [수업 신청] 화면에서 원하는 수업의 선택 → 확인. “신청이 완료되었습니다”가 보이면 끝!
